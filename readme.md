# Usurper's Travels

Is a game I started working on to develop my Python and Pygame programming skills in preparation for my A-level Computer Science project. Its a turn-based hack-n-slash rougelike RPG thats heavily inspired by games I love such as Dark Souls and Path of Achra. 

This is the first and only proper game I've made, and I didn't realise how complex it would be to make or balance it (especially without a proper game engine!), so some parts of the game are very poorly balanced - but isn't the point of a roguelike for you to be comically over (or under) powered by the end?

Although Its been a few years and I should really be working on other, more important things, I keep coming back to this project from time to time. Despite being unintuitive to play, poorly designed, and having a story written by a terrible writer (me!) its still *my* game, and I don't think I'll ever have the heart to abandon it.
